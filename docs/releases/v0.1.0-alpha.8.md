# MagicHandy v0.1.0-alpha.8

This corrective release restores the full Windows setup executable after
Microsoft completed its review of the withdrawn alpha.6 artifact with final
determination `Not malware` and removed the Defender detection.

## Install

Download these files:

- `MagicHandy-0.1.0-alpha.8-windows-amd64-setup.exe`
- `MagicHandy-0.1.0-alpha.8-windows-amd64-SHA256SUMS.txt`

The portable ZIP is also available for users who do not want Windows installer
integration. Verify the setup hash before running it:

```powershell
(Get-FileHash .\MagicHandy-0.1.0-alpha.8-windows-amd64-setup.exe -Algorithm SHA256).Hash.ToLowerInvariant()
Get-Content .\MagicHandy-0.1.0-alpha.8-windows-amd64-SHA256SUMS.txt
```

Run the setup EXE, choose the installation directory and optional desktop
shortcut, then complete device, model, and voice choices in the browser setup
flow. The core needs no Go, Node, Python, CMake, Visual Studio, or CUDA Toolkit.
Optional components download only after an explicit setup action.

## Defender Review And Packaging

- Microsoft Security Intelligence submission
  `15c1e36d-fb35-4c5d-85de-83707169818a` completed with final determination
  `Not malware`; Microsoft reported that the alpha.6 detection was removed.
- Alpha.8 is a new build and hash. Its setup uses a native x64 loader with
  non-solid `zip/9` compression instead of alpha.6's 32-bit loader and solid
  ultra-LZMA stream.
- The exact public setup is built from the tagged payload, checked as x64 and
  unsigned, covered by the outer checksum, and exercised through custom and
  Program Files install, over-install, retention, purge, uninstall, and clean
  reinstall before publication.
- The reviewed unsigned release policy is bound to alpha.8; a later unsigned
  setup requires a new explicit repository decision.
- Pull-request setup files remain short-lived `unsigned-ci` artifacts and have
  no release permission.

The alpha.8 executables remain unsigned. Do not disable Defender or bypass a
new malware classification. Preserve the checksum and report any new detection
so the affected release can be withdrawn and investigated.

## Upgrade And Data

Exit any existing MagicHandy process, then run the alpha.8 setup over an
existing packaged installation. The stable app identity preserves
`%APPDATA%\MagicHandy` and applies forward-only database migrations at startup.
Export irreplaceable personas, chats, and patterns before testing prereleases.

Portable alpha.7 users should keep the extracted folder separate or move to the
installer deliberately; do not copy portable files into Program Files by hand.

## Known Alpha Limits

- The Windows binaries have no Authenticode publisher identity yet.
- Models, Python, llama.cpp, Parakeet, and TTS runtimes are not bundled and may
  require several GiB after explicit selection.
- The in-app update checker follows stable releases and does not announce alpha,
  beta, or release-candidate builds yet.
- Pre-1.0 settings, APIs, and user flows may change.
