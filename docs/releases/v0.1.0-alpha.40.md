# MagicHandy v0.1.0-alpha.40

## Changelog

- Creative v2 adds generated directional sweeps, local and broad strokes,
  shrinking rebounds, and adjustable inertia to main chat.
- Layered adds persistent motion with independent reach, location and pace
  layers, relative edits, and evolving variation.
- Autopilot can develop the new modes without repeated user requests while
  preserving requested motion characters and exact repetition.
- Longer bounded chat history improves continuity and recall, and ordinary
  conversation in Creative v2 no longer conflicts with its edit format.
- Motion descriptions use the active mode's controls, and direct speed
  adjustment requests work more reliably.
- The new continuous pattern library replaces retired defaults; old default
  patterns are disabled during migration when updating.
- Optional Labs can be enabled in Settings in every build, with conversation,
  motion previews, guided feedback tests and a separate Help tab.
- Smaller models can still omit parts of compound motion requests or describe
  an action inaccurately. Motion limits and Emergency Stop remain active.
