# MagicHandy v0.1.0-alpha.85

## Changelog

- Fix ChatGPT reconnection when using the public address on the MagicHandy PC: **Open local sign-in** takes you to the host's direct address. Direct same-PC LAN access can reconnect; remote browsers still cannot start a host-only OAuth flow.
- Keep ChatGPT account controls available during model discovery and checks, and discard results from an earlier account after reconnecting.
- Add **Answer roleplay cues with motion** for Advanced Layered and Creative v2 chat. It defaults on. Switching it off keeps more conversation replies text-only and may reduce latency; direct motion requests and explicit Stop remain available. Simple and Intermediate behavior is unchanged.
- Add experimental **Autoblow Ultra** and **VacuGlide** cloud connections, device settings and simulator support. Ultra follows position targets; VacuGlide follows pace with manual valve steps and an optional experimental reach follower. Physical timing and feel have not yet been verified on either device.
- Harden the new connections against stale commands after Stop, uncertain valve replies, repeated health failures and reconnect replay. Reconnecting stays idle; linked-device failure policies still apply. Tokens are protected against redirect forwarding and redacted from diagnostics.
- Autoblow commands, including Stop, require the internet and Autoblow's cloud. If that path fails, switch the device off locally. The valve follower defaults off.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.85`.
