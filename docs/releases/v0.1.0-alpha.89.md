# MagicHandy v0.1.0-alpha.89

## Changelog

- Resume uses the stroke window, reversal and speed limit you last saved. Saving unrelated Diagnostics settings preserves newer live adjustments.
- Emergency Stop distinguishes a device-confirmed stop from a pending or unconfirmed stop. Rapid live adjustments can take effect sooner, and secondary pages load less data on first visit.
- Signed-in ChatGPT with GPT-6.1 Terra can make pace-only edits to an active Layered pattern while preserving its range and rhythm. It can also restore the previously commanded pace.
- Supported local Gemma profiles can use a longer conversation history at 32K context. Gemma 4 E4B can start a motion chat at the supported 16K minimum using a compact guide. Exact follow-ups still vary by model and conversation.
- This Windows x64 alpha was reviewed with simulated transport. The installer is unsigned, so Windows may show a publisher warning.
- Run setup over the previous installation to preserve settings, accounts and chat history. For portable updates, close the app before replacing its program files. Source tag is `v0.1.0-alpha.89`.
