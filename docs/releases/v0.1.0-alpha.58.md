# MagicHandy v0.1.0-alpha.58

## Changelog

- Added hosted models. Setup's Easy path now offers Local-only AI, ChatGPT (sign in with your ChatGPT plan) and API / Cloud (OpenRouter, the OpenAI API or another compatible provider, with your own API key and separate billing). Chat and Autopilot can use different connections, and you can keep chat local while a cloud model plans Autopilot from motion details only. A hosted refusal or timeout does not fall back to another model on its own. An opt-in setting can retry a refused request once with your local model, and every accepted reply still goes through the same motion engine and limits. Credentials stay on this computer and never appear in logs, diagnostics or exports. The hosted-model design (ADR 0039) is still "Proposed; pending final independent review", so treat hosted connections as a preview.
- Redesigned Setup and Settings on one card, choice and row system. A fresh install now starts Easy setup on Local-only AI with the model recommended for your graphics card.
- Applied the Graphite visual system across the app and the phone remote: one card level with label-left rows and switches, an in-app confirmation dialog, keyboard-friendly menus, and a flat connection strip in place of the generated artwork. The phone remote now lays out like Chat, with 16 px composer text so focusing it does not zoom, and a 48 px Stop.
- The motion visualizer now draws the device in use: a dot display for the Handy 2 Standard and Pro, a front view of the original Handy with its range bracket, and a scanning bar for Intiface. Handy models read their commanded position in millimetres.
- Creative v2 now accepts replies from models whose server ignores the response schema, such as some macOS MLX servers, when a reply puts several controls in one edit. Duplicates, unknown controls and partial groups are still rejected, and nothing is repaired or replaced.
- External llama.cpp servers now receive the standard `json_schema` request form, which LM Studio documents and Ollama's OpenAI-compatible endpoint honors. With reasoning off, requests also send `reasoning_effort: "none"`. Previously, Ollama's OpenAI-compatible endpoint kept thinking models reasoning until they ran out of output.
- Creative v2 now resolves requested reach before texture. Requests such as "stay in the upper quarter" keep strokes inside that band instead of sweeping the whole slider. Local Gemma 12B passed the reach-steering fixture 24/24, against 18/24 before. The guide applies where the response schema is enforced (hosted models, Ollama and the managed llama.cpp runtime). An external server, which may drop the schema, keeps the earlier contract.
- Technical-context Autopilot can now vary pace and reach, using motion details only.
- Built with Go 1.26.9, which fixes the reachable standard-library vulnerabilities reported against Go 1.26.8.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
