# MagicHandy v0.1.0-alpha.58

## Changelog

- Added hosted models as a preview. Easy setup offers Local-only AI, ChatGPT (your ChatGPT plan) and API / Cloud (OpenRouter, the OpenAI API or another compatible provider, with your own key). Chat and Autopilot can use different models, and chat can stay local while a cloud model plans Autopilot from motion details only. Credentials stay on this computer. The hosted-model design (ADR 0039) is still "Proposed; pending final independent review".
- A hosted refusal or timeout does not switch models on its own. An optional setting retries a refused request once with your local model; every reply still goes through the same motion engine and limits.
- Redesigned Setup and Settings. A fresh install starts Easy setup on Local-only AI with a model chosen for your graphics card.
- Applied the Graphite visual style across the app and the phone remote, with an in-app confirmation dialog and keyboard-friendly menus. The remote now lays out like Chat.
- The motion visualizer draws your device: a dot display for the Handy 2, a front view of the original Handy, and a scanning bar for Intiface.
- Creative v2 accepts replies from servers that ignore the response format, such as some macOS MLX servers, when several controls share one edit. Invalid replies are still rejected, never repaired.
- External llama.cpp servers, including LM Studio and Ollama's OpenAI-compatible endpoint, now receive the standard response format, and requests with reasoning off ask the server to skip it.
- Creative v2 now keeps requests like "stay in the upper quarter" inside that band instead of sweeping the whole slider.
- Technical-context Autopilot can now vary pace and reach.
- Built with Go 1.26.9 for standard-library security fixes. Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
