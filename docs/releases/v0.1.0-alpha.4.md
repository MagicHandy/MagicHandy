# MagicHandy v0.1.0-alpha.4

This corrective Windows alpha hardens clean-machine managed voice setup. It
also includes the verified llama.cpp bundles, retry-safe TTS source checkout,
and bounded setup Model Library from the previous corrective releases.

## Install

Download `MagicHandy-0.1.0-alpha.4-windows-amd64-setup.exe`. Setup defaults to
`C:\Program Files\MagicHandy`, allows another destination, and offers an
optional desktop shortcut. Optional models and workers install only after an
explicit choice in guided setup.

The installer is currently **unsigned**. Windows may display an unknown
publisher or SmartScreen warning. Verify the download against
`MagicHandy-0.1.0-alpha.4-windows-amd64-SHA256SUMS.txt` before running it:

```powershell
(Get-FileHash .\MagicHandy-0.1.0-alpha.4-windows-amd64-setup.exe -Algorithm SHA256).Hash.ToLowerInvariant()
Get-Content .\MagicHandy-0.1.0-alpha.4-windows-amd64-SHA256SUMS.txt
```

The portable ZIP contains the same core payload without Windows shortcuts or
Add/Remove Programs integration.

## Managed Voice Setup

- A freshly installed WinGet `uv.exe` alias is no longer trusted merely
  because it exists. Setup probes candidates and falls back to the executable
  inside the real WinGet package directory when an alias cannot launch.
- Git is version-probed and exposed to child installers, including
  Chatterbox's pinned `git+https` engine dependency.
- App-owned constraint files keep the API-sensitive Faster Qwen and Chatterbox
  dependency versions repeatable instead of resolving open-ended versions on
  each installation.
- Chatterbox now receives its pinned upstream ONNX/protobuf compatibility
  override and engine-compatible NumPy/safetensors versions.
- Before a multi-gigabyte model download begins, setup verifies the Hugging
  Face launcher, provider-specific Python and native imports, and the selected
  CUDA backend. Faster Qwen additionally receives a strict dependency-graph
  check.
- Native SoX and FFmpeg are not required. The managed Qwen model uses its 12 Hz
  tokenizer, and both managed services exchange WAV audio.

The source checkout and compatible virtual environment remain reusable after
an interrupted install. Actual source edits, unrelated untracked files, wrong
remotes, and non-Git source directories remain protected hard stops.

## Upgrade And Uninstall

Install this build over an earlier alpha to retain settings and managed
components. A partial managed voice install can be retried from guided setup;
download caches and compatible environments are reused.

Interactive uninstall asks whether to remove app-owned data from
`%APPDATA%\MagicHandy`; choose **Yes** for a clean reinstall. Silent uninstall
purges that directory unless `/KEEPUSERDATA` is supplied. External Ollama
models, media and funscript folders, source checkouts, and custom data
directories are never removed.

## Known Alpha Limits

- Windows binaries are unsigned.
- Models, Python, llama.cpp, Parakeet, and TTS runtimes are not bundled;
  selected managed components can require several GiB of downloads.
- The in-app update checker follows stable GitHub releases. It does not announce
  alpha, beta, or release-candidate builds yet.
- Pre-1.0 settings, APIs, and user flows may change. Database migrations remain
  forward-only, so export irreplaceable personas, chats, and patterns before
  testing.
