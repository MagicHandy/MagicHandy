# MagicHandy v0.1.0-alpha.91

## Changelog

- The Handy requests the next part of its motion earlier over Cloud. This gives a delayed refill more time to arrive. Playback stops if the buffer runs out.
- In long chats, you can ask for the first paces you requested, a later adjustment, or a detail you named earlier. MagicHandy checks the original messages in that chat and identifies missing information. Looking up a past instruction leaves playback alone.
- Inkling 2 Mini is an optional local model for a separately installed Basalt server. For the tested setup, use a loopback OpenAI-compatible connection, Intermediate capability and the prompt-contract output setting. Automatic output also supports Basalt's schema. Setup recommends Gemma 4 E4B or 12B according to your hardware.
- Faster Qwen and Chatterbox now check and install Hugging Face's Xet download support when needed. If a compatible wheel is unavailable or a Xet transfer fails, setup can finish the model download over HTTP. Existing modules pick this up on their next managed voice-module update.
- This Windows x64 alpha was tested with simulated motion. The installer is unsigned, so Windows may show a publisher warning.
- Run setup over your existing installation to keep settings, accounts and saved chats. For a portable update, close MagicHandy before replacing its program files. The source tag is `v0.1.0-alpha.91`.
