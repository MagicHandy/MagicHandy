# MagicHandy v0.1.0-alpha.81

## Changelog

- Add an optional Advanced (no reasoning) capability level for capable models running with reasoning off. It adds a brief planning step to Layered and Creative v2 chat, improving tested DeepSeek motion requests without adding a second generation. Existing capability selections and ChatGPT defaults stay unchanged.
- Add OpenRouter Host order choices in Setup and Settings: Fastest output, Fastest first token, Lowest price, and OpenRouter balanced. New connections prefer Fastest output; existing connections retain their routing. Faster hosts can cost more.
- Give external connections enough output room for their selected capability level, and reserve additional room when OpenRouter reasoning is enabled. This reduces incomplete structured replies. Reasoning can increase latency and token use.
- Keep automatic response repair available for both Advanced levels. Clarify that capability selection does not change the model's reasoning setting, and distinguish temporary provider rate limits from exhausted credit.
- Model accuracy still varies. DeepSeek remains less reliable than GPT on several complex patterns and repairs; the new level is optional and does not change device limits or bypass response validation. No new physical-device behavior is claimed in this release.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.81`.
