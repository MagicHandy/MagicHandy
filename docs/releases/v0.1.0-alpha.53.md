# MagicHandy v0.1.0-alpha.53

## Changelog

- The Remote item in the main app's menu opens the Remote again. Since alpha.51 it showed "browser requests must use an allowed MagicHandy origin" instead. Opening the Remote by its address, as phones do, was not affected.
- On Windows, a Gemma 4 model that uses the automatic chat template fix no longer fails to load when two loads start at once, such as the startup load and the first chat message.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
