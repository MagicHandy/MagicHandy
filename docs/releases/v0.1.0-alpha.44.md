# MagicHandy v0.1.0-alpha.44

## Changelog

- Improve model switching and cancellation so an old llama.cpp model cannot
  restart after it has been replaced or closed.
- Limit combined chat history and saved memories to reduce oversized prompts
  and unnecessary prompt processing. Saved memories remain intact.
- Add model loading, prompt processing, token counts and input-budget details
  to response diagnostics, with a panel that fits small browser windows.
- Begin supported PCM/WAV speech playback before generation finishes, while
  preserving speech order and canceling pending playback after Stop or loss of
  controller ownership.
- Improve Qwen3-TTS and Chatterbox responsiveness and cancellation. Chatterbox
  serves only its private speech and health endpoints.
- Detect a stopped Parakeet server, reduce speech-upload memory use, and discard
  short noise bursts without delaying the next hands-free phrase.
- Support ElevenLabs keys limited to speech access and use consistent timeouts
  for slow OpenAI-compatible speech generation.
- Prepare managed TTS updates in separate version directories so a failed update
  leaves the running environment intact. Previous versions remain on disk.
- Automatically detect outdated managed TTS modules and prompt in Notifications
  and Voice settings. Update on request with progress/cancel controls while
  preserving model, voice and reference settings. Speech quality and shared-GPU
  performance remain under alpha evaluation.
- Windows x64 installer and portable downloads retain the reviewed unsigned
  alpha policy. Install over the existing version to preserve settings, chats,
  and models. Source users can run `update.ps1`.
