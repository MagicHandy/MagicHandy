# MagicHandy v0.1.0-alpha.52

## Changelog

- Easy setup is the new first-run default. It checks your graphics card, memory and disk, says whether chat, voice output and voice input will run, picks a tested model, and asks only how explicit chat should be and whether you want voice. Custom setup keeps every step.
- Setup can download a tested chat model: a 12B model for cards with about 10 GB or more, or a faster E4B model for 6 to 8 GB cards. Downloads resume, are verified by SHA-256, and are selected when finished.
- Settings > Chat > Model > Test model checks the selected model for hidden reasoning, broken or cut-off replies, slow speed, GPU placement, long replies and refusals. It runs only when you start it and never moves the device.
- Known Gemma 4 E4B builds that reasoned silently before every reply are fixed automatically. The model test offers the same fix for other Gemma 4 files.
- Reply length (Short, Balanced, Detailed) sits in the Model settings, and personas can override it.
- The managed llama.cpp runtime moves to b11149. MagicHandy installs it at the first start after updating unless you turn off automatic runtime updates in General settings; the bell announces runtime updates, and old runtime copies are removed.
- The Device step asks which Handy you have, remote access stays folded away until requested, and voice can turn on as soon as it installs.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
