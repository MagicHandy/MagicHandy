# MagicHandy v0.1.0-alpha.15

## Changelog

- Fixed asking for a long reply, such as a story, ending in a connection error
  instead of an answer. A reply that runs past the output limit is now shown as
  far as it was written, rather than being sent back to the model for a
  correction that could not fit either. The failing case took about half as long
  and returns text instead of an error. Replies that fit are unaffected.
  If you want longer replies before the cut-off, raise the maximum output tokens
  in Settings > Model.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Verify it with the checksum file and install it over an existing package to
preserve app data.
