# MagicHandy v0.1.0-alpha.59

## Changelog

- Rebuilt Settings > Chat > Model. Model roles chooses the Chat and Autopilot models from providers you have already added, so picking a role no longer creates a provider. External providers (formerly Named connections) lists every hosted or compatible provider and the Decisions API, with its status, the roles that use it, Edit and Remove.
- You can now remove a provider. Removing one asks first, names the roles that will switch to the local model, and is undone by Discard. Its stored API key is deleted when you save settings.
- Setup and Settings share one provider editor, laid out as rows.
- Setup labels ChatGPT, API / Cloud and Hosted model as Experimental. Hosted models remain a preview under ADR 0039, which is still "Proposed; pending final independent review".
- The Handy 2 dot display now moves smoothly. Its lit row glides between samples like the original Handy's carriage instead of jumping a row at a time.
- The Intiface scanning bar's trail is now one continuous tail that follows the bar and folds back on each reversal, instead of separate blocks.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
