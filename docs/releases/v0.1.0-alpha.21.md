# MagicHandy v0.1.0-alpha.21

## Changelog

- Kept alpha.20's reviewed pattern pacing and model-catalog changes: pattern
  shape and `speed_percent` remain independent, safety retiming covers loop
  seams and focused ranges, and model choices use semantic geometry metadata.
- Corrected the Pattern Library summary after final live review. Library
  toggles now report how many patterns are enabled instead of claiming that
  every enabled experimental pattern is available to Chat. Experimental
  patterns remain excluded from the model catalog unless the user explicitly
  enables that capability in Model settings.

The exact released app was checked in the browser against a fresh isolated
data directory. It rendered the 87-entry catalog without browser warnings or
errors. No physical device motion was commanded during this release review.

## Install Or Update

Download the setup EXE and SHA-256 checksum file from this release. Verify the
checksum, then run setup over the existing installation to preserve
`%APPDATA%\MagicHandy`, including settings, chats, personas, models, patterns,
and optional module state. This release corresponds exactly to source tag
`v0.1.0-alpha.21`.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Windows may still show an unknown-publisher reputation warning. Do not bypass a
malware detection; report the exact filename and checksum instead.
