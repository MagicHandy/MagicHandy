# MagicHandy v0.1.0-alpha.45

## Changelog

- Add a one-click **Download failure report** button after guided setup,
  TTS module update, or Parakeet repair fails. The report includes recent
  installer output and system details with credentials and local paths redacted.
- Keep the latest failure report available after retries and app restarts.
  A prompt encourages users to review it and share it with the developer.
- Show the failing installer operation and its exit code when available,
  making voice-module installation errors easier to diagnose.
- Check the NVIDIA driver before downloading dependencies for an explicitly
  selected Chatterbox CUDA installation.
- Remove extra silence between arriving speech chunks and add adaptive
  buffering to smooth uneven delivery. Playback may wait briefly to collect
  audio; sustained generation below real time can still cause pauses.
- Make Stop interrupt speech waiting on new audio or browser audio activation,
  and reduce memory copying during streamed speech playback.
- The originally reported Chatterbox failure is not yet reproduced. CPU
  dependency installation and native imports pass; model listening and
  shared-GPU performance remain under alpha evaluation.
- Windows x64 installer and portable downloads retain the reviewed unsigned
  alpha policy. Install over the existing version to preserve settings, chats,
  and models. Source users can run `update.ps1`.
