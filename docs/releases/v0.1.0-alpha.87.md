# MagicHandy v0.1.0-alpha.87

## Changelog

- Add the MagicHandy hand-and-star mark to the navigation rail, startup screens and phone-remote header, preserving the approved artwork and layout.
- Add a centered-star browser icon that follows the saved theme.
- Replace the earlier theme catalog with eight coordinated palettes: Steel Azure, Warm Titanium, Ember, Midnight Gold, Forest Brass, Harbor, Carbon and High Contrast. Steel Azure and Warm Titanium keep their existing colors.
- A saved theme removed from the catalog falls back to Steel Azure after updating. Choose another palette in Settings → General; changes apply after Save settings. The phone remote continues to use the default palette.
- Preserve the existing motion controls and safety colors across the new palettes. This update changes branding and themes; Windows executable and installer artwork remain as before.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.87`.
