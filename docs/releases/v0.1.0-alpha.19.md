# MagicHandy v0.1.0-alpha.19

## Changelog

- Improved Autopilot pattern and area variation without taking the hold/change
  decision away from the model. Autonomous turns temporarily leave recently
  played patterns out of the available catalog while still allowing the model
  to keep the current pattern or change only its pace.
- Added denser, sampled speed texture inside longer Autopilot stretches. These
  adjustments keep the current pattern and focus, preserve motion phase, stay
  inside the configured speed band, and continue through the shared motion
  engine. Timing guards keep the measured combined retarget rate below the
  existing churn ceiling.
- Avoided a redundant repair request when an autonomous model names a pattern
  outside its current catalog. The bounded planner fallback now takes over
  immediately instead of waiting for the model to repeat the same invalid ID.

Model-path validation used the installed local 26B and 12B Gemma models. Across
18 autonomous decisions, both completed without contract errors, selected four
and five patterns respectively, and used focused areas as well as the full
range. This was a decision-path test; no physical device motion was commanded
during release validation.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Verify it with the checksum file and install it over an existing package to
preserve app data.
