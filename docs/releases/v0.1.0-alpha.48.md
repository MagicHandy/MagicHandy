# MagicHandy v0.1.0-alpha.48

## Changelog

- Creative v2 Autopilot no longer settles into one repeated quick sweep toward the same point. Unequal timing, rebounds and heavy inertia are now short accents that fade unless Autopilot chooses them again.
- Autopilot follows what you said recently instead of fixed keyword rules, so words like "harder" no longer lock a session. Asking chat to keep the motion exactly as it is holds Autopilot until you ask for a change.
- Pace can use your whole saved speed range. After "that's too much", or when Autopilot decides to hold you off after "I'm close", it drops near your minimum at once, stays there a while and then builds back up gradually. A request to go slow keeps it slow.
- Autopilot now knows how long ago you spoke, so an old remark is not treated as a fresh reaction minutes later.
- Layered answers "mix it up" and "surprise me" with a new motion instead of a small variation of the same one.
- Chat can bring back a pattern that played earlier in the Autopilot session when you praise it or ask for it again.
- Creative v2 strokes breathe more naturally, with gentle pace drift, occasional quick flurries, rare brief pauses at a turn and slightly varied landing points. Default variation rises from 35 to 50; 0 still repeats exactly.
- Layered alternating strokes run closer to the requested pace.
- These motion changes were tested with simulated sessions, not yet on a physical device. Smaller local models (3–4B) follow the new pace choices less reliably and rarely bring back earlier patterns; with Gemma 12B, the earlier pattern chosen matched the one you meant about half the time.
- Windows setup remains unsigned under the reviewed alpha policy. Install this version over the existing app to preserve its data; portable users replace the application files while the app is stopped.
