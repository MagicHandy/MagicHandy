# MagicHandy v0.1.0-alpha.22

## Changelog

- Corrected a pattern-timing regression that could make short partial returns
  feel like a stop after an upstroke once mean-rate speed normalization was
  applied. `Hard and Regular` keeps its full-range geometry and 16-beat shape,
  but its full and partial legs now use proportional timing.
- Corrected the same class of slow segment in `Deep-Partial Sequence` and at
  the `Tease` loop seam.
- Added two-cycle continuity coverage for the non-experimental default catalog
  and Cloud-resolution wire-frame coverage for `Hard and Regular` at 35% and
  40%. The longest unintended low-velocity interval in that pattern at 40%
  fell from about 950 ms to 45 ms.
- Existing databases receive corrected built-in timing while preserving user
  renames, enablement, and pattern weights.

The diagnosis used a retained Cloud REST device trace. It showed continuous,
accepted HSP timestamps during the recurring pause; a later network failure
was a separate recovery event. The corrected app was checked against an
isolated data directory and the 87-pattern library. No physical device motion
was commanded after the correction because the user-launched connected session
was preserved.

## Install Or Update

Download the setup EXE and SHA-256 checksum file from this release. Verify the
checksum, then run setup over the existing installation to preserve
`%APPDATA%\MagicHandy`, including settings, chats, personas, models, patterns,
and optional module state. This release corresponds exactly to source tag
`v0.1.0-alpha.22`.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Windows may still show an unknown-publisher reputation warning. Do not bypass a
malware detection; report the exact filename and checksum instead.
