# MagicHandy v0.1.0-alpha.47

## Changelog

- Streamline initial setup and Access settings with Local only, LAN + local, and Public choices, automatic address detection, and exact firewall and port-forwarding instructions.
- Add guided local certificates and automatically issued public HTTPS certificates, including renewal and advanced manual-certificate or reverse-proxy options.
- Fix certificate preparation reporting ready before its temporary validation port was released.
- Correct Handy Bluetooth position and stroke-range values that could clamp movement to an endpoint; reduce unnecessary sampled points while preserving the shared motion shape.
- Improve Bluetooth buffering, clock synchronization, reconnect isolation, command timeouts, and Stop handling.
- Improve Intiface connection keepalive, device discovery, and failure handling, plus Handy Cloud buffering and interrupted-command reliability.
- Give mobile Chat more conversation space, keep its composer visible, and fix clipping and centering of the connection manager button on phones and desktop.
- Public certificate issuance and renewal require reachable external TCP 443; LAN certificates require explicit trust on each client. Setup explains the required steps and does not change the router or firewall automatically.
- Real-device motion feel and physical mobile-keyboard acceptance remain alpha validation limits. Handy 2 direction timing through Intiface also depends on the installed Intiface/Buttplug driver version.
- Windows setup remains unsigned under the reviewed alpha policy. Install this version over the existing app to preserve its data; portable users replace the application files while the app is stopped.
