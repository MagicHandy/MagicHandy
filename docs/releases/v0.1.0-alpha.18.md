# MagicHandy v0.1.0-alpha.18

## Changelog

- Fixed Autopilot barely varying the device speed. Most of its motion decisions
  were being thrown away before they reached the device: the instructions it was
  given asked for a pacing choice the response contract rejects, so the app fell
  back to a fixed plan almost every time. Measured on a local 26B model, 18 of
  20 decisions were lost before this change and none are now. Speed moves across
  a much wider part of your allowed range, and Autopilot reaches its decisions
  about twice as fast because it is no longer spending a second request trying to
  repair each one.

Autopilot still tends to stay on one pattern and on the full stroke range for a
whole session; that is a separate limitation and is not fixed here.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Verify it with the checksum file and install it over an existing package to
preserve app data.
