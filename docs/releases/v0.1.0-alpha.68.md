# MagicHandy v0.1.0-alpha.68

## Changelog

- Reduce unnecessary WAN chat interruptions with faster controller heartbeat retries and better handling of temporary status connection failures.
- Increase the default idle sign-out from 30 minutes to eight hours. Change it or turn idle sign-out off in Settings → Access → Sessions; the existing maximum session lifetime still applies.
- Improve ChatGPT pace descriptions and compound motion requests, including alternating faster and slower movement at different ends of the stroke. Existing speed limits remain enforced without forcing a preferred speed.
- Improve Layered turning points, buffered timing, and pace-change transitions to reduce unintended pauses and abrupt changes. Physical Handy Cloud comparison remains pending.
- Fix a vibrator shutdown race affecting concurrent state updates.
- Existing device limits remain: Intiface Central may acknowledge Stop without delivering it to The Handy; use Native Bluetooth or Handy Cloud for its device Stop path. Loaded COYOTE output and real vibrator behavior remain unverified, and a native Bluetooth worker crash may require reconnecting both devices.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.68`.
