# MagicHandy v0.1.0-alpha.72

## Changelog

- Make Layered the default for new settings, with Layered then Creative v2 first in the LLM motion list. Existing saved mode choices are preserved.
- Improve generated-motion smoothness for a single Original Handy using Handy Cloud. Real-device comparisons favored fewer position updates while preserving stroke endpoints, counts and timing. Some hesitation at direction changes can remain.
- Keep finer precision for narrow strokes. Imported scripts, motion transitions, Bluetooth, Intiface, Handy 2 and multi-device sessions retain their existing fitting behavior.
- Improve ChatGPT Layered responses when editing compound patterns, retaining a person's lasting travel restriction, releasing an old restriction, or retrying a request that previously failed. Later edits preserve the motion actually applied.
- Help local Layered chat start an explicitly requested rhythm while keeping questions and explanations stationary. Existing start safeguards remain; smaller local models can still miss complex regional requests and some starts in legacy modes.
- Preserve a clear interruption warning when a pending chat response ends unexpectedly, and retain timeout causes and the actual hosted reasoning setting in Diagnostics.
- Existing device limits remain: Intiface Central may acknowledge Stop without delivering it to The Handy; use Native Bluetooth or Handy Cloud for its device Stop path. Physical multi-Handy synchronization, loaded COYOTE output and real vibrator behavior remain unverified.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.72`.
