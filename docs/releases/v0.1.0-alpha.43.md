# MagicHandy v0.1.0-alpha.43

## Changelog

- Fix video synchronization failures at fractional seek positions by checking
  startup arrival against the position the device transport actually encodes.
- Avoid redundant startup moves when the device has already reached that
  encoded position. Preserve the existing arrival tolerance and Stop checks.
- Include the encoded startup target and arrival tolerance in diagnostic
  traces to make device-position errors easier to investigate.
- Windows x64 installer and portable downloads retain the reviewed unsigned
  alpha policy. Install over the existing version to preserve settings, chats,
  and models.
