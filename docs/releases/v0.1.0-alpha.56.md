# MagicHandy v0.1.0-alpha.56

## Changelog

- Easy Setup now offers Qwen3-TTS and Chatterbox with short explanations of their performance and setup requirements. Qwen is preferred on NVIDIA unless the combined chat and voice memory estimate is insufficient.
- Memory warnings account for the selected chat model, voice engine and desktop reserve. You can still choose Qwen below the estimate; unmeasured models and unknown GPU memory are labeled unconfirmed.
- Qwen setup now guides you through choosing a WAV audio sample and entering its exact transcript. Both are required before Qwen can speak. You can install it now and set up the voice later, keeping spoken replies off.
- The guide preserves saved references and checks WAV format and duration before saving. It cannot verify that the transcript matches the recording. Memory figures remain estimates; simultaneous chat/voice peaks and listening quality have not been benchmarked for this update.
- HTTP API test fixtures now reuse an empty migrated database while retaining a private datastore for every test, reducing race-test setup time.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
