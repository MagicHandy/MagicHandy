# MagicHandy v0.1.0-alpha.92

## Changelog

- Edge eases into a gentler moving hold using your speed limits. The control shows when the change is queued, when motion is slowing, and when the hold has settled. Hold still pauses playback. Vibration-only sessions keep the slider idle.
- With a conversation-aware Autopilot planner set to Advanced (with reasoning), feedback such as “that was too close” can change the duration and return pace of the next moving hold. You can also ask for a specific duration or pace. A request about the next hold leaves the current one alone.
- Return stays available for a hold you can resume. A repeated Edge press after Hold still leaves an unrelated chat reply in progress.
- In long chats, MagicHandy tells you when it could not run a history search and when it could not verify a detail in the saved messages. Looking up an old instruction keeps playback as it is.
- If chat uses a hosted model, you can load or unload a separately assigned local planner or fallback in Settings. Changing that local model lets your hosted chat finish.
- Linked playback checks that every participating device acknowledged an update. VacuGlide rejects late tempo updates during Stop, and Coyote blocks queued reconnects during shutdown.
- This Windows x64 alpha was tested with simulated devices. The installer is unsigned and Windows may show a publisher warning.
- Run the installer over your existing copy to keep your settings and saved chats. For a portable update, close MagicHandy before replacing its program files. The source tag is `v0.1.0-alpha.92`.
