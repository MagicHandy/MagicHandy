# MagicHandy v0.1.0-alpha.26

## Changelog

- Creative motion can now vary stroke length independently of pace, center
  drift, and decision cadence. The model selects an outer range, a bounded span
  floor, and one of four compact profiles: steady, breathe, wander, or contrast.
- Breathe produces a long asymmetric swell, wander follows a smooth correlated
  phrase, and contrast groups irregular tight, medium, and broad strokes. The
  phrases are deterministic, loop-closed, and at least about 30 seconds long at
  the fastest supported normal Handy profile; they do not add sample jitter.
- Existing alpha.25 Creative targets keep their prior bounded variation
  behavior. New variable profiles require a usable model-selected floor, so the
  backend does not invent how much range to remove.
- Long Creative phrases now receive a curve-complexity-aware retarget phase
  search. The handoff scorer evaluates the direction actually available after
  the replacement starts, avoiding a coarse or reversal-side match when
  changing profiles.
- Creative state, Autopilot context, diagnostics, and the motion visualizer now
  report the outer/floor range and profile. The browser remains a view of the
  backend target and does not synthesize motion.
- Scoped negative qualifiers preserve the named semantic axis: asking for a
  new stroke-length feel without changing pace no longer cancels the whole
  update. Unscoped motion refusals remain inert.
- The final model contract more clearly states that example numbers are not
  live speed targets and that nested JSON fields must keep their declared type.

## Evaluation

The installed managed 12B Gemma model passed 16/16 repeated span-envelope cases
and the broader 9/9 Creative intent matrix on its first response, with zero
repairs or fallbacks. Coverage included variable start, legacy-to-breathe,
contrast, steady-to-variable, variable-to-steady, pace-only preservation,
unchanged continuation, conversation-only hold, slow and anchored starts,
focus, negation, pacing, broad variation, and Stop.

Those model tests instantiate neither the motion engine nor a transport and
cannot dispatch a device command. Planner tests separately cover profile
bounds, acceleration, loop closure, all three Handy calibration choices,
continuity, trace fields, and the shared engine path. A matched capped-device
A/B run is still required before claiming that Creative feels less robotic in
physical use or making it the default. The supported Ollama quality matrix also
remains open for the expanded schema.

## Install Or Update

Download the setup EXE and SHA-256 checksum file from this release. Verify the
checksum, then run setup over the existing installation to preserve
`%APPDATA%\MagicHandy`, including settings, chats, personas, models, patterns,
and optional module state. This release corresponds exactly to source tag
`v0.1.0-alpha.26`.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Windows may still show an unknown-publisher reputation warning. Do not bypass a
malware detection; report the exact filename and checksum instead.
