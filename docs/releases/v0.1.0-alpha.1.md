# MagicHandy v0.1.0-alpha.1

This is the first public Windows alpha of MagicHandy. It is intended for
hands-on testing of the local-first app, setup flow, device transports, chat,
patterns, video/funscript playback, personas, speech recognition, and optional
local model and voice integrations.

## Install

Download `MagicHandy-0.1.0-alpha.1-windows-amd64-setup.exe`. Setup defaults to
`C:\Program Files\MagicHandy`, allows a different destination, and offers an
optional desktop shortcut. The embedded setup page then configures optional
models and workers; those larger dependencies are downloaded only after an
explicit choice.

The installer is currently **unsigned**. Windows may display an unknown
publisher or SmartScreen warning. Verify the download against
`MagicHandy-0.1.0-alpha.1-windows-amd64-SHA256SUMS.txt` before running it:

```powershell
(Get-FileHash .\MagicHandy-0.1.0-alpha.1-windows-amd64-setup.exe -Algorithm SHA256).Hash.ToLowerInvariant()
Get-Content .\MagicHandy-0.1.0-alpha.1-windows-amd64-SHA256SUMS.txt
```

The portable ZIP contains the same core payload without Windows shortcuts or
Add/Remove Programs integration.

## Upgrade And Uninstall

Install a newer build over the same directory to retain settings and managed
components. Interactive uninstall asks whether to remove app-owned data from
`%APPDATA%\MagicHandy`; choose **Yes** for a clean reinstall. Silent uninstall
purges that directory unless `/KEEPUSERDATA` is supplied. External Ollama
models, media and funscript folders, source checkouts, and custom data
directories are never removed.

## Known Alpha Limits

- Windows binaries are unsigned.
- Models, Python, CUDA, llama.cpp, Parakeet, and TTS runtimes are not bundled;
  selected managed components can require several GiB of downloads.
- The in-app update checker follows stable GitHub releases. It does not announce
  alpha, beta, or release-candidate builds yet.
- Pre-1.0 settings, APIs, and user flows may change. Database migrations remain
  forward-only, so export irreplaceable personas, chats, and patterns before
  testing.
