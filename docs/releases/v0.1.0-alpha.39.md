# MagicHandy v0.1.0-alpha.39

## Changelog

- Settings → Voice now hides runtime plumbing for MagicHandy-managed speech
  modules while keeping custom-server and custom-worker controls under Advanced.
- Managed Parakeet has one direct **Repair Parakeet** action and shows missing
  worker, runner, model, saved-partial, byte-progress, and cancellation status.
- Fresh and interrupted Parakeet installs now use a resumable Go downloader with
  free-space and writability checks, a pinned model revision, and SHA-256 checks.
- Repair stops an active app-owned speech-input worker and restores it only after
  the runner and model have both passed verification.
- Parakeet setup is preselected when saved settings, runtime files, or a partial
  download show that the user already chose or started installing it.
- A bounded, sanitized last Parakeet install result survives app restarts and a
  switch between source and packaged installation.
- Managed Qwen3-TTS and Chatterbox statuses now direct users to in-app setup
  rather than source-only PowerShell scripts.
- Background Voice-status polling keeps the existing snapshot and scroll position
  instead of flashing the initial loading row or shifting the page.
- Parakeet remains an optional Windows/amd64 download of roughly 646 MiB;
  Faster Qwen3-TTS still requires a compatible NVIDIA GPU with CUDA.
