# MagicHandy v0.1.0-alpha.41

## Changelog

- Reduce false Creative v2 and Layered response rejections, including pace
  paraphrases, translated requests, and changing one control while keeping
  another unchanged.
- Let the model interpret the conversation when choosing motion changes.
  Ordinary replies can leave motion unchanged; paused motion cannot resume
  through a generated reply. Saved limits and Emergency Stop remain active.
- Improve request following with live llama.cpp testing on Gemma 12B,
  Gemma E4B Heretic Q4_K_M, and Granite 3B. The selected prompt avoids extra
  planning passes or automatic repair attempts.
- Models can still misunderstand compound requests or describe motion they
  have not selected. Smaller models remain less reliable in these cases.
- Windows x64 installer and portable downloads retain the existing reviewed
  unsigned alpha packaging policy. Installing over an existing version
  preserves its settings, chats, and models.
