# MagicHandy v0.1.0-alpha.12

## Changelog

- Fixed Ollama imports that looked compatible but contained fused audio or
  vision components the managed llama.cpp text runner could not load. Existing
  incompatible copies now show `unsupported` with a clear explanation.
- Fixed slow repaired chat replies appearing to repeat, including malformed
  repair and Emergency Stop persistence races.
- This unsigned prerelease is portable-only because the reviewed setup
  exception ended with alpha.11. Verify the ZIP with the checksum file, extract
  it, and run `magichandy.exe`.

Alpha.8-alpha.11 setup users should first stop MagicHandy and uninstall the old
package from Windows Installed apps while choosing to keep user data. Extract
alpha.12 to a user-writable folder outside Program Files; do not overwrite the
old install. The portable app reuses `%APPDATA%\MagicHandy`.
