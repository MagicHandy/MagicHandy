# MagicHandy v0.1.0-alpha.14

## Changelog

- Fixed chat replies falling into the same sentence shape over and over, where
  nearly every sentence started with "I" and personas began to read alike. On
  the 12B test model this dropped from roughly 70% of sentences to under half,
  and replies came back with a wider vocabulary. How explicit the reply may be
  is unchanged: the voice levels, their limits, and the persona's own manner all
  behave exactly as before.

This is a small release. Apart from the reply fix it carries documentation and
test tooling only, and the Windows setup EXE remains unsigned, Defender-scanned,
and lifecycle-tested. Verify it with the checksum file and install it over an
existing package to preserve app data.
