# MagicHandy v0.1.0-alpha.83

## Changelog

- Say when Edge interrupts a pending chat reply, or cancels motion and speech after the reply was saved. Chat and the phone remote share the translated explanation. Quick-control interruption diagnostics now name model or motion settings consistently.
- Give Advanced Layered Autopilot observations of its three most recent distinct scores, finished within three minutes, to help it vary strokes while retaining the requested direction and qualities. This includes Advanced local connections; the observations contain no recall IDs or conversation text.
- Guide Advanced chat to act on the immediate part of a request while waiting for a later cue, and represent Layered stroke-by-stroke progressions as counted steps. Simple/Intermediate prompts, Creative v2 planning and Auto timing retain their existing behavior.
- Correct the recent-score window for long Autopilot stretches. Fresh model and simulator checks passed, while model choices can still miss requests. Physical feel and the previously unrun opt-in evaluation rows remain unverified.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.83`.
