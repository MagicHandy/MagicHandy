# MagicHandy v0.1.0-alpha.25

## Changelog

- Fixed a process-ending panic in Creative motion. A full-span phrase at some
  variation values—96% is the reduced regression case—could round a semantic
  endpoint to `100.00000000000001`. The strict curve validator correctly
  rejected that out-of-range value, but alpha.24 discarded the compilation
  error and later sampled an empty curve.
- Clamp the final floating-point center/span projection to the semantic
  `0..100` range, including sub-ULP endpoint overshoot after otherwise bounded
  geometry calculations.
- Preserve motion-plan compilation errors and make Engine Start, Resume,
  retarget, and live settings refresh reject an invalid plan before sampling or
  issuing a transport command.
- Make zero-value curve sampling fail stationary at the semantic midpoint
  instead of indexing an empty point list. This is a last-resort process-safety
  guard; the engine still rejects the originating invalid plan.
- Added exhaustive regression coverage for every Creative variation percentage
  across Original Handy, Handy 2 Standard, and Handy 2 Pro, plus direct empty-
  curve sampling coverage.

The fix remains inside the one shared semantic motion planner. Transport
interfaces and payloads, controller ownership, Emergency Stop, speed
calibration, persisted settings, and the alpha.24 sidebar design are unchanged.

## Diagnosis

The installed alpha.24 process left no Windows Application Error, Windows Error
Reporting entry, Reliability Monitor incident, or crash dump. Its installer
shutdown event was an earlier intentional Restart Manager handoff. The exact
installed binary then started normally from the user's existing database and
survived 900 concurrent settings updates plus repeated rendered sidebar and
Handy-model interactions against a device-key-free database clone.

A deterministic planner stress test subsequently reproduced the process-killing
panic in `Curve.sampleFloat`: the rejected Creative curve had no compiled
points, so sampling indexed point zero of an empty slice. The endpoint clamp
removes the triggering numerical error, and the compilation/fallback guards
prevent the same failure class from becoming another whole-process panic.

No real-device connection or motion command was used during diagnosis. The
matched post-calibration real-device A/B acceptance run requested by alpha.24
remains open.

## Install Or Update

Download the setup EXE and SHA-256 checksum file from this release. Verify the
checksum, then run setup over the existing installation to preserve
`%APPDATA%\MagicHandy`, including settings, chats, personas, models, patterns,
and optional module state. This release corresponds exactly to source tag
`v0.1.0-alpha.25`.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Windows may still show an unknown-publisher reputation warning. Do not bypass a
malware detection; report the exact filename and checksum instead.
