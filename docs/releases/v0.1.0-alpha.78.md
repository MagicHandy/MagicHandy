# MagicHandy v0.1.0-alpha.78

## Changelog

- Keep active motion on the same stream when a manual chat request supersedes an Autopilot update whose upload is still awaiting acknowledgement. Stop and Pause still cancel the active update, and genuine transport failures retain recovery Stop.
- Recommend GPT-6.1 Terra with Low reasoning for new ChatGPT connections when the account offers it. Existing saved models and reasoning choices stay selected; accounts without Terra keep the available-model fallback. Matched motion tests found faster responses with the same overall intent-check score, while retaining failures from both models.
- The chat/Autopilot overlap fix is verified with an inert transport; uninterrupted physical Handy Cloud motion still needs a device check. Existing vibrator acceptance gaps, Intiface Stop limitations and the installed-app full-range speed discrepancy remain unresolved. Models can still misunderstand requests.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.78`.
