# MagicHandy v0.1.0-alpha.34

## Changelog

- Creative Autopilot now treats the active mode and saved controls as the
  user's continuing authorization for bounded autonomous motion. Quiet chat no
  longer biases hidden motion turns toward tiny midpoint edits or indefinite
  continuity.
- The model sees the current compiled position envelope and a bounded history
  of four recent compiled envelopes as observations, names a short destination
  intent before encoding geometry, and samples more broadly as Motion change
  rate rises. No percentage band defines “broad,” no range preset is injected,
  and no elapsed-time threshold forces a change.
- Model-elected geometry is compiled through the shared motion planner before
  admission. Nearby numerical variants become honest holds; at high change
  rates one semantic retry may reconsider the motion concept without receiving
  replacement coordinates. A simultaneous real pace change remains valid.
- The aggregate felt-difference gate still rejects small scalar nudges while
  admitting combined near-full position, stroke-length, and texture changes.
  Creative Wander also approaches its selected outer span more often through
  the existing smooth correlated envelope, without endpoint pinning or jitter.
- Autopilot Pause is latched before transport Stop begins. The transient state
  where the engine is already idle but has not yet published `paused=true` can
  no longer trigger recovery Start and resume motion behind the user's back.
  Explicit Resume preserves the phrase, clocks, and remaining speed schedule.
- Spoken check-ins use a moderate sampling temperature independent of Motion
  change rate, reducing repeated first-person openings without adding
  persona-specific response templates.

## Diagnosis And Evaluation

Read-only inspection of the running user-installed alpha.33 Cloud session found
4,824 emitted motion points over 403.5 seconds. Only 1.46% of commanded time was
below position 10 and 0.45% was above 90. Its first 15 retained Creative phrases
clustered around center 48–52 and span 40–45; lower/base travel appeared
reliably only after explicit chat instructions. The model could therefore use
the range, but ordinary hands-off turns interpreted the default behavior
profile's “do not escalate” language as stronger than Autopilot's lower-priority
user-message authority.

The same trace captured two successful UI Pause requests. Each stopped the
engine, briefly exposed `running=false, paused=false` while the Cloud Stop was
in flight, and was followed about 2.2 seconds later by autonomous startup
recovery and Play. The fix is a mode-generation pause latch around the existing
shared engine call; it adds no transport bypass or second motion loop. A
regression advances five simulated minutes through that exact transient state
and observes no model decision, Start, or retarget. A failed Pause releases the
latch, and explicit Resume continues the preserved stream.

Transport-free evaluation used the exact active installed llama.cpp model,
`n0404n0404-gemma-4-12b-it-heretic-b9a462-239ec3629639`. On the final qualitative
prompt, a ten-turn hands-off max-rate run progressed from a localized phrase
through authored spans 45, 68, 82, and 92, admitted multiple material geometry
changes, approached the base, and retained genuine holds. The model was never
given a numeric definition of broad motion or a turn on which it had to change.
An explicit-direction run produced five valid three-section phrases with
smooth local stroke-length variation, then obeyed “keep the motion exactly as
it is” at a 180-second phrase age. Three repeated four-line Hei speech runs
passed the recent-line, opening-variety, and first-person-default checks after
the independent speech sampling adjustment.

A fresh isolated alpha.34 review app used a new data directory, fake transport,
and no connection key. The mandatory readiness script completed a real
generation on the same llama.cpp model: “I am ready to proceed with the
review.” A text-only request through MagicHandy's actual chat path then replied,
“The MagicHandy app chat path is confirmed to be working,” with no repair,
semantic fallback, motion, or TTS. LLM motion was restored to Creative after
the probe; Autopilot remained Off, the engine remained idle, the motion trace
was empty, and fake transport retained zero commands.

Full Go tests, vet, zero-issue pinned lint, the pure-Go build, frontend
localization, typecheck/build and 408 tests pass locally. The timing-sensitive
startup-hold assertion also passed 100 consecutive repetitions after it was
synchronized with the trace it inspects. Local Windows race remains unavailable
because no C compiler is installed; the mandatory Ubuntu CI race gate is
authoritative for publication.

The local Go 1.26.4 candidate is 24,167,936 bytes plain and 17,394,176 bytes
release-style stripped. The production frontend is unchanged from alpha.33.

No post-change physical motion was commanded. The user-installed alpha.33
process, app data, device connection, controller lease, and managed model were
not stopped or replaced. Subjective capped-device feel and Pause/Resume/Stop
confirmation remain open.

## Install Or Update

Download the setup EXE and SHA-256 checksum file from this release. Verify the
checksum, then run setup over the existing installation to preserve
`%APPDATA%\MagicHandy`, including settings, chats, personas, models, patterns,
programs, and optional module state. This release corresponds exactly to source
tag `v0.1.0-alpha.34`.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Windows may still show an unknown-publisher reputation warning. Do not bypass a
malware detection; report the exact filename and checksum instead.
