# MagicHandy v0.1.0-alpha.73

## Changelog

- Keep a desktop session available while its phone remote is open and in front, including when the desktop tab is in the background. Video and chat continue through the desktop's existing controls.
- Add Edge and Return beside Stop on the phone. They work directly through the server when the desktop tab is asleep, and pending presses are cancelled by Stop or controller handoff.
- Show when the phone holds a background desktop session. On protected installs, locking or closing the phone ends the hidden desktop's session after about 15 seconds. Local unprotected installs keep their existing expiry policy.
- Browser limits still apply: frozen or discarded desktop tabs cannot carry out video or chat commands, Browser Bluetooth disconnects on hide, and background timer throttling can stop synchronized video motion. Edge and Stop remain available from the phone.
- Existing device limits remain: Intiface Central may acknowledge Stop without delivering it to The Handy; use Native Bluetooth or Handy Cloud for its device Stop path. Physical multi-Handy synchronization, loaded COYOTE output and real vibrator behavior remain unverified.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.73`.
