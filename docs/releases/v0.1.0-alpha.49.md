# MagicHandy v0.1.0-alpha.49

## Changelog

- Starting MagicHandy on Windows now opens a branded console window instead of a stream of technical logs, with a magic wand and sparkles beside the MagicHandy name.
- The window shows the app address as a link you can Ctrl+click in Windows Terminal, whether MagicHandy is running, who can reach it, and recent activity in plain language.
- Press O to open MagicHandy in your browser, C to copy the link, S or Esc to stop motion, D to show details, and Q twice to quit. Closing the window still stops the app.
- If MagicHandy cannot start, for example because its port is in use, the window now stays open with the reason until you press a key.
- In the classic Windows console, links are not clickable and the sparkles use simpler characters; press O to open the app.
- Windows setup remains unsigned under the reviewed alpha policy. Install this version over the existing app to preserve its data; portable users replace the application files while the app is stopped.
