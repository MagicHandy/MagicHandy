# MagicHandy v0.1.0-alpha.84

## Changelog

- Guide Advanced Layered and Creative v2 chat to keep replies and motion in step when responding to invitations, feedback, and requests to rest. Praise usually preserves the current motion; a fresh invitation can begin playback from stopped.
- Let Advanced live chat explicitly Stop playback, including Autopilot, through the shared Stop path. Stop carries no motion or vibration changes, works while paused, and never resumes playback. A later fresh request can start again.
- Keep Simple/Intermediate prompts and autonomous action contracts unchanged. The new guidance also applies to Advanced local connections.
- Model choices can still miss the requested pace. Retained trials showed a median response-time increase of about 0.7–0.8 seconds; these were not controlled latency benchmarks. No new hardware smoothness or physical-feel validation is claimed.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.84`.
