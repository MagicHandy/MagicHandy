# MagicHandy v0.1.0-alpha.27

## Changelog

- Creative motion now brakes and accelerates across each complete stroke leg
  with shape-preserving PCHIP easing. It reaches zero velocity at a true turn
  without spending most of the leg at a linear velocity followed by a sudden
  endpoint brake.
- Stored Pattern Library curves keep their shorter acceleration-budgeted
  reversal guides, preserving their authored rhythm. Both profiles still use
  the same curve compiler, exact 7500%/s² runtime limiter, sampler, transport
  stream, and unconditional Stop path.
- Wander and contrast change their correlated stroke-length target at roughly
  two-cycle cadence and deliberately explore tight, middle, and broad portions
  of the selected floor-to-outer range. Breathe retains its long asymmetric
  swell but adds restrained local texture. No profile adds per-sample noise.
- Ordinary Creative variation values are more perceptible. Center drift and
  grouped leg timing use independent seeded texture and a square-root response,
  while pace, outer reach, stroke-length envelope, variation, and decision
  horizon remain separate semantic axes.
- Chat now verifies that a claimed tip, base, or full-length correction actually
  reaches the requested region. Terse follow-ups such as "still not" retain the
  previous position request for validation, while true refusals remain inert.
- A position-only correction cannot silently change pace, stroke-length
  texture, center/rhythm variation, or decision horizon. Unrelated fields from
  the model are treated as unauthorized noise instead of expanding the prompt
  with phrase-specific edge cases.

## Evaluation

The reported installed Cloud REST trace contained 439 points and 85 legs. Its
contrast envelope contracted from about 80% to about 32%, then stayed within
roughly 31–35% for more than 30 reversals. Most adjacent append
acknowledgements were about 330–341 ms; one network error was recorded, and the
user's Stop succeeded in 330 ms. That separates a range plateau and abrupt
endpoint shape from high-frequency jitter, but it predates this correction.

Planner tests require every six-cycle wander/contrast window to explore at
least 18% of its available range and reject four-cycle plateaus below 8%.
Separate tests verify gradual whole-leg braking, exact zero velocity at the
turn, the runtime acceleration ceiling, and retention of the eased shape after
buffering and 1% transport quantization.

The installed managed 12B Gemma model passed the broader 25/25 Creative matrix
and 9/9 repetitions of the reproduced recent position-correction sequence.
Those tests construct neither a motion engine nor a transport. A capped
post-change device run and the supported Ollama matrix remain open, so Creative
remains opt-in and Pattern Library remains the default.

## Install Or Update

Download the setup EXE and SHA-256 checksum file from this release. Verify the
checksum, then run setup over the existing installation to preserve
`%APPDATA%\MagicHandy`, including settings, chats, personas, models, patterns,
and optional module state. This release corresponds exactly to source tag
`v0.1.0-alpha.27`.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Windows may still show an unknown-publisher reputation warning. Do not bypass a
malware detection; report the exact filename and checksum instead.
