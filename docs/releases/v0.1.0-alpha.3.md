# MagicHandy v0.1.0-alpha.3

This corrective Windows alpha fixes managed local TTS installation retries and
contains the setup Model Library within the app viewport. It includes the
verified managed llama.cpp bundles introduced in `v0.1.0-alpha.2`.

## Install

Download `MagicHandy-0.1.0-alpha.3-windows-amd64-setup.exe`. Setup defaults to
`C:\Program Files\MagicHandy`, allows another destination, and offers an
optional desktop shortcut. The embedded setup page configures optional models
and workers only after an explicit choice.

The installer is currently **unsigned**. Windows may display an unknown
publisher or SmartScreen warning. Verify the download against
`MagicHandy-0.1.0-alpha.3-windows-amd64-SHA256SUMS.txt` before running it:

```powershell
(Get-FileHash .\MagicHandy-0.1.0-alpha.3-windows-amd64-setup.exe -Algorithm SHA256).Hash.ToLowerInvariant()
Get-Content .\MagicHandy-0.1.0-alpha.3-windows-amd64-SHA256SUMS.txt
```

The portable ZIP contains the same core payload without Windows shortcuts or
Add/Remove Programs integration.

## Managed TTS Retry Fix

- The Faster Qwen3-TTS and Chatterbox source checkout is staged beside its
  final directory and moved into place only after the Git clone succeeds.
- A fresh no-checkout clone no longer fails its own dirty-tree guard. Rerunning
  alpha.3 also recovers the empty checkout left by the alpha.2 failure.
- Actual tracked edits, unrelated untracked files, non-Git directories, and a
  checkout from the wrong remote remain hard stops and are never cleaned.
- Existing compatible Python environments, installed packages, and resumable
  model caches continue to be reused.

## Setup Layout Fix

- Setup now fits the routed app viewport instead of growing beneath the page.
  Its progress rail, heading, and actions stay visible while the step body
  scrolls.
- Managed-model selection, direct GGUF import, and Ollama-library import are
  separate labeled regions.
- Large Ollama scans use a bounded internal model list, keeping filters, import
  actions, and the setup footer within their intended surfaces.

## Upgrade And Uninstall

Install this build over either earlier alpha to retain settings and managed
components. A failed alpha.2 TTS install can be retried from guided setup; no
manual source-directory deletion is required when that checkout is empty.

Interactive uninstall asks whether to remove app-owned data from
`%APPDATA%\MagicHandy`; choose **Yes** for a clean reinstall. Silent uninstall
purges that directory unless `/KEEPUSERDATA` is supplied. External Ollama
models, media and funscript folders, source checkouts, and custom data
directories are never removed.

## Known Alpha Limits

- Windows binaries are unsigned.
- Models, Python, llama.cpp, Parakeet, and TTS runtimes are not bundled;
  selected managed components can require several GiB of downloads.
- The in-app update checker follows stable GitHub releases. It does not announce
  alpha, beta, or release-candidate builds yet.
- Pre-1.0 settings, APIs, and user flows may change. Database migrations remain
  forward-only, so export irreplaceable personas, chats, and patterns before
  testing.
