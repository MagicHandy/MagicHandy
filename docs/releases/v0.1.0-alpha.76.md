# MagicHandy v0.1.0-alpha.76

## Changelog

- Preserve rounded slow strokes beside faster strokes in Layered patterns, keeping their intended contrast and stroke counts.
- Make gentle Edge entries and motion changes use acceleration and jerk limits suited to the two patterns. Some gentle joins take longer to finish the current turn and enter the new stroke smoothly.
- Avoid unnecessary extra direction changes after rapid buffered Layered edits while preserving motion already queued for playback.
- Correct Estimated pace reporting so deliberate pattern variation is distinguished from physical fitting limits. Show effective and selected pace when they differ; these remain commanded estimates, not measured device speed.
- The new transition feel has not been physically verified. Previously accepted alpha.75 full-range, short and counted pattern timings are retained; the installed-app versus matched-test full-range speed discrepancy remains unresolved.
- Transports too slow to represent a stroke still reject it explicitly. Automatic transport-aware retiming remains separate work. Existing Intiface Stop limitations still apply.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.76`.
