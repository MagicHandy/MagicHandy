# MagicHandy v0.1.0-alpha.75

## Changelog

- Let Layered use more of The Handy's speed range while retaining rounded turns, stroke counts, deliberate pace changes and softer motion. Full-range, short and compound patterns were physically compared over Handy Cloud and judged faster while remaining smooth.
- Improve large speed changes during playback so they can join the next stroke smoothly. Show estimated effective pace alongside the requested value in Layered and Creative v2; this is a command estimate, not measured device speed.
- Improve Qwen speech startup, streamed-audio recovery and cancellation, and Parakeet loading and recovery. Voice settings now distinguish loading, readiness and real failures, with compact Graphite controls and expandable diagnostics.
- Fix Autopilot requests being rejected before reaching the model, expose repeated planning failures, and report the provider that actually produced each check-in.
- Make Emergency Stop cancel chat with a clear explanation while keeping the signed-in connection usable for the next request.
- One reported difference between installed-app speed and matched test playback remains unexplained. The faster Layered changes have not been physically validated on every transport or Handy model. Existing Intiface Stop limitations still apply.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve data; portable users replace application files while the app is stopped. Source: `v0.1.0-alpha.75`.
