# MagicHandy v0.1.0-alpha.30

## Changelog

- Creative motion now fits each interval locally to the selected Handy model's
  calibrated velocity instead of slowing an entire phrase to the single most
  demanding leg. The speed control is monotonic again: higher selected speeds
  produce meaningfully higher compiled travel while the shared engine still
  enforces the exact C2 curve's velocity, acceleration, jerk, and reversal-gap
  limits.
- The slow `Breathe` stroke profile now combines a broad swell with bounded,
  correlated local drift. It varies effective stroke length inside short
  windows without adding random point jitter or flattening against clamp
  shelves.
- Creative plans publish one compact perceptual summary of the trajectory the
  engine actually compiled. Autonomous decisions can see measured bounds,
  stroke-length variation, local flatness, commanded travel, anchor, profile,
  and section count; the summary informs the model but never creates a forced
  change threshold.
- Autonomous one-section Creative replacements receive a fresh bounded,
  deterministic phrase seed. Holds, pace-only edits, and decision-horizon
  changes keep the current phrase and seed, so continuity remains explicit.
- The existing 2–4-section schema is now presented to local models as the way
  to express an explicitly requested evolving or multi-sequence phrase. It is
  not required for an ordinary adjustment or hold, and sections still compile
  through the one shared motion engine.
- Motion-change countdowns now reconcile to absolute backend deadlines. The
  UI interpolates presentation locally between backend snapshots, so it no
  longer skips whole seconds at the polling cadence, compresses elapsed time,
  or jumps when a paused session is resumed.
- Session buildup continues to count active time only. Its 20-minute scale now
  has direct clock coverage across active, paused, and resumed intervals.

## Install Or Update

Download the setup EXE and SHA-256 checksum file from this release. Verify the
checksum, then run setup over the existing installation to preserve
`%APPDATA%\MagicHandy`, including settings, chats, personas, models, patterns,
programs, and optional module state. This release corresponds exactly to source
tag `v0.1.0-alpha.30`.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Windows may still show an unknown-publisher reputation warning. Do not bypass a
malware detection; report the exact filename and checksum instead.
