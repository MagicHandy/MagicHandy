# MagicHandy v0.1.0-alpha.16

## Changelog

- Fixed being dropped back into setup after an update, with no way to decline
  and the same thing happening on every launch. MagicHandy now asks whether you
  want to run setup, and stays where you were if you say no. A brand-new
  installation still opens setup directly, and Settings > General still offers
  **Run setup again** at any time. The same fix covers a setup that was closed
  part-way through, which previously also forced the wizard open every launch.

The Windows setup EXE remains unsigned, Defender-scanned, and lifecycle-tested.
Verify it with the checksum file and install it over an existing package to
preserve app data.
