# MagicHandy v0.1.0-alpha.90

## Changelog

- Pages look right again on first load. Chat's Autopilot card no longer shows an extra box, and the persona switcher, device connection choices and several settings panels have their layout back.
- ElevenLabs speech works again with current ElevenLabs accounts, including free plans and keys limited to Text to Speech. New setups default to the Jessica voice on Eleven v4 Turbo. If you were using the retired default voice, it changes to Jessica automatically; your chosen model is kept.
- Settings › Voice can check an ElevenLabs key without spending credits. It shows the plan, the credits used, and what the key is allowed to do.
- Change voice… browses your ElevenLabs voices and the Voice Library, with previews and suggested searches such as Warm & close, Soft & breathy and ASMR. Using Voice Library voices from MagicHandy needs a paid ElevenLabs plan (Starter or higher). Default voices and your own voices work on every plan.
- Delivery offers only the controls the selected ElevenLabs model supports: stability, similarity, style, speed and language.
- Turning on Speak replies now starts the voice output. If replies can't be spoken, Chat shows the reason with a link to Settings.
- ElevenLabs replies start playing sooner, and long replies are no longer cut off.
- Replies spoken by ElevenLabs are sent to ElevenLabs and follow its Prohibited Use Policy. For speech that stays on this computer, use Faster Qwen3-TTS or Chatterbox.
- This Windows x64 alpha was reviewed with simulated transport. The installer is unsigned, so Windows may show a publisher warning.
- Run setup over the previous installation to preserve settings, accounts and chat history. For portable updates, close the app before replacing its program files. Source tag is `v0.1.0-alpha.90`.
