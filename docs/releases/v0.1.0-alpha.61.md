# MagicHandy v0.1.0-alpha.61

## Changelog

- Local chat and Autopilot can optionally get a motion second opinion from an external model. Local choices take effect immediately; a timely review can correct a materially poor choice. Enable it in Settings > Chat > Model.
- External providers offer Recent, Long and Extended conversation history for longer stories and continuing motion directions. Local models keep their existing prompt limits. Longer history depends on model capacity and can increase response time and API usage.
- Creative v2 uses more of the requested pace on broad strokes while preserving motion limits, narrow strokes and deliberate rests. Cloud playback also handles difficult curve transitions more reliably; physical feel still needs real-device feedback.
- Chat retains recent request failures with inspectable model output and prompts. Diagnostics can test the saved chat configuration without moving the device.
- Prompt settings distinguish editing from assigning a prompt set, show the effective persona/default selection, and expose the complete live prompt. Creative v2 action instructions and examples are clearer.
- Autonomous check-ins can choose silence and plan what to say before replying. Repetition remains model-dependent; no wording filters or canned replies are added.
- Diagnostics downloads one customizable report with status, settings and traces, plus optional full retained chat history, failed output, personas, prompts and memories. Credentials are redacted, and personal content is opt-in.
- Expanded external-provider settings have clearer contrast and dividers. Hosted connections and motion second opinions remain experimental.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
