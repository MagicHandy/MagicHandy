# MagicHandy v0.1.0-alpha.60

## Changelog

- Choosing an Intiface actuator during a Bluetooth scan now stops the scan, and the top bar shows the device as connected instead of "Finding a linear device".
- Settings > Device calls the connection choice Protocol instead of Dispatch owner.
- The Local LLM and Managed models cards in Settings > Chat > Model now have the same header rows as the other cards.
- The launcher, setup and updates now give a newly installed app 30 seconds to start instead of 10, so a slow first start after an antivirus scan is no longer stopped and reported as a failure.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
