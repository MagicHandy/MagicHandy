# MagicHandy v0.1.0-alpha.46

## Changelog

- Add secure LAN/WAN access through self-hosted HTTPS or a trusted reverse proxy, with explicit network settings and administrator password confirmation.
- Improve account recovery, session management and remote control permissions, including permanent permission and immediate retirement of disabled or signed-out sessions.
- Keep remote control, reconnects and Emergency Stop reliable under slow connections, stale commands and stalled viewers.
- Consolidate Chat settings and simplify Access navigation, with more compact mobile controls and centrally saved notice preferences.
- Improve motion timing, endpoint transitions and Bluetooth/Intiface playback feedback.
- Fix Chatterbox installation failures and compatibility with both Windows PowerShell and PowerShell 7.
- Fix startup dialogs that dimmed only part of the page.
- Update Go to 1.26.8, close queued administrator-request security gaps and add vulnerability checks for source and packaged executables.
