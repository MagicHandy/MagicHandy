# MagicHandy v0.1.0-alpha.57

## Changelog

- Fixed Handy Cloud connection checks rejecting valid five-, six- and seven-character keys as malformed. Existing short keys can now be used without regenerating them to meet the app's old eight-character minimum.
- Connection-key validation follows the current API v3 schema: 5–64 letters or digits. It preserves case, trims pasted outer whitespace and explains the accepted format without displaying the key.
- Updated Cloud API references and regression coverage for short keys, REST and SSE authentication, and diagnostic/trace redaction. Connection checks still read status without starting motion; device availability and firmware/HSP errors are reported separately.
- Windows setup remains unsigned under the reviewed alpha policy. Install over the existing app to preserve its data; portable users replace the application files while the app is stopped.
